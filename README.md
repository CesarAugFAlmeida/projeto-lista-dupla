# Trabalho de Estrutura de Dados sobre a Lista Duplamente Encadeada.

Este é meu projeto para um trabalho de meio de semestre da minha matéria de Estrutura de Dados que demonstra as características da lista duplamente encadeada.

O projeto tem como proposta ser um sistema de assistência de matrícula em uma escola de ensino fundamental.

O programa possui duas listas, uma se trata dos alunos matriculados na escola e a outra sendo dos alunos que foram transferidos. No programa é possível:

* Adicionar alunos na lista principal;
* Remover alunos da lista principal;
* Adicionar estudantes em uma lista de alunos transferidos e 
excluí-los da lista principal;
* Localizar o aluno por seu nome matriculado.
